================================================================
  用户数据守护 —— 先看这个（30 秒）
================================================================

【它解决什么问题】
  项目更新（换版本 / 重新跑建表脚本 / 换库）时，用户数据会被清空：
  账号、成员关系、模拟测试记录、反馈 全没了，而且往往登录时才发现。
  这个小工具会提前把用户数据存起来，更新后检测、确认后搬回来。
  剧情/角色/世界观这些"作品内容"一个字都不动。


【怎么用（五步，都靠双击）】

  第 1 步   双击  1-填配置.bat
            按提示填 MySQL 密码和要保护的数据库名，其它直接回车。
            填完的答案存在 guard.config.local.json（不会被上传到 Git）。

  第 2 步   双击  2-建立保险箱.bat
            把现在的用户数据存进"保险箱"。
            （以后用户数据有较大变化时，再双击一次刷新。）

  第 3 步   双击  3-检查一次.bat
            只看一眼状态，不改任何数据：
              ✅ 正常   🟡 数量有变化（只提示）   🔴 灾难（库/表没了或账号清零）

  第 4 步   双击  4-开始监控.bat
            窗口开着就行。它【默认只报警、不写库】——发现异常会打印提示。

  第 5 步（确认是灾难后）双击  5-人工恢复.bat
            流程：校验快照 → 核验身份与关联 → 备份 → 写入 → 写后核验。
            写之前会问你一句，回车默认不写。


【安全设定（放心的地方）】
  · 只碰白名单里的库（就是你第 1 步填的那个），绝不扫描/写入其他数据库
  · 正常删成员、清测试数据只会提示"数量有变化"，不会自动把旧记录推回来
  · 发现 id 被占用的账号冲突 / 关联对不上时，会直接中止，不写错绑数据
  · 写库前一定先备份；写库后还会再核验一遍，不通过就报失败


【前提条件】
  · 装了 Python 3.10 或更高版本（安装时记得勾选 "Add python.exe to PATH"）
  · 本机有 MySQL，且能连上（密码就是第 1 步填的）
  · 不需要安装任何第三方 Python 包


【注意】
  · vault 文件夹里存的是用户数据快照（含密码哈希），自己留着别外发
  · guard.config.local.json 里有你的数据库密码，同样不要外发、不要提交
  · 所有命令和更多说明见 README.md
