用户数据守护 v3

1. 填配置：1-填配置.bat（真实密码只写本地配置）
2. 健康数据库停写后：2-建立保险箱.bat
3. 日常只读检查/报警：3-检查一次.bat、4-开始监控.bat
4. 异常时先停写、保留现场，运行 python guard.py restore --dry-run。
5. 确认后再人工恢复：5-人工恢复.bat。

只支持同库 v3 快照，不按同名项目映射，不跨库搬运，不自动恢复。
已有保险箱不会自动覆盖；旧 v1/v2 备份务必保留。
禁止数据丢失后重建快照覆盖旧备份。
本轮仅做离线测试，真实 MySQL 必须先在隔离库验收。
完整边界、测试命令见 README.md。
