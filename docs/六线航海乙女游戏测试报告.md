## 三、发现的问题

### P1：隐藏路线解锁状态无法跨模拟测试保留

**现象**：

`hidden_routes_unlocked` 初始值为 `false`，而罗吉线、希尔法法线等隐藏路线要求该变量为 `true` 才会出现。完成四条主线后，即使解锁逻辑将该变量设为 `true`，一旦重新开始模拟或新开模拟，状态会恢复初始值 `false`，隐藏路线再次不可见。

**影响**：

- 无法在模拟测试中验证“累计打通四条主线后解锁两条隐藏路线”的多周目玩法。
- 隐藏路线的真实可达性无法完成验收。
- 当前状态变量只能承载单次模拟会话状态，不能承载跨会话永久进度。

**建议**：

将“单次模拟状态”和“玩家持久进度”分开保存。好感度、线索数等随重新开始而重置；已通关主线、隐藏路线解锁标记应保存为玩家进度／存档，并在每次模拟启动时读取。建议同时提供重置进度或测试预设，便于测试隐藏路线。

详细说明见：[隐藏路线跨模拟解锁问题报告.md](隐藏路线跨模拟解锁问题报告.md)。

## 四、问题检测模块补充结果

### BUG-01：筛选结果与右侧详情不同步

**严重程度：中，建议优先级：P1**

选中问题后改变筛选条件、搜索关键词或处理问题，左侧问题可能已经被过滤掉，但右侧仍保留旧问题详情；筛选结果为空时也可能残留旧详情。

预期是当前选中问题不属于结果集时清空或自动切换详情，结果为空时显示空状态。

详细记录见：[问题检测模块测试记录.md](问题检测模块测试记录.md)。

## 六、模拟测试补充结果

1. TESTER 可以从“航程第七日”创建模拟会话。
2. `hidden_routes_unlocked = false` 时隐藏路线不会出现在可用选项中。
3. 选择主线选项后，步骤、路线推进度、角色好感度和线索数会正确变化。
4. 刷新并重新选择会话后，步骤和状态能够恢复。
5. 新建会话不会覆盖旧会话，多个会话状态相互独立。
6. “重新开始”会创建新会话，旧会话保留为已终止历史，已终止会话不能继续选择。

结论：单次模拟会话及多会话隔离基本正常；跨模拟永久解锁问题仍需修复或确认设计。

## 七、账户设置补充结果

输入错误当前密码、合法新密码和一致确认密码后，页面跳回登录页，但使用原密码仍可登录，新密码没有生效。

结论：错误当前密码不会修改密码，核心安全性通过；失败后没有明确提示且直接跳回登录页，属于交互/错误处理问题。建议只有密码修改成功后才清除 JWT 并跳转登录页。
