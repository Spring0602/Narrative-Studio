## 3. 后续核心验收案例

第3周后端的状态模拟、类型错误、规则引用、会话越权、事务回滚与并发提交已覆盖自动化测试，证据和复现方式见 [第3周后端验收记录](09-第3周后端验收记录.md)。页面端到端与真实 MySQL 验收仍单独记录，不能用内存库测试替代。

### 权限越权

用户甲创建项目 A，用户乙不加入项目，尝试用 A 的 `projectId` 和节点 ID 读取或修改。所有请求都应返回 403/404，数据不改变。

### 状态模拟

初始 `trust=30`，选择一执行 `ADD 20`，下一节点仅当 `trust >= 50` 时展示隐藏选项。执行后该选项可见，步骤快照分别保存 30 和 50。

### 类型错误

对 INTEGER 变量设置 `abc`，保存规则时应返回 400；不得等到运行剧情时才失败。

### 图检测

构造 10 个节点：1 个起点、2 个结局、1 个孤立节点、1 个意外死路、3 节点循环。检测结果应分别定位，不应把正常结局标为死路。

### 引用保护

变量被条件引用时删除，应返回 409 并提示引用位置；节点作为选项目标时删除也应阻止或要求显式重连。

## 4. 非功能性验收基线

- 普通 CRUD 在本机测试环境中 P95 响应小于 500 ms。
- 单项目 500 节点、1000 条边的结构检测在 2 秒内完成。
- 密码不明文存储，日志不打印 JWT、密码和 AI Key。
- 生产模式下密钥均由环境变量注入。
- 关键写操作失败后数据库无半成品记录。

## 5. 答辩前冻结标准

数据库扩展接口的自动化测试范围、新增权限边界和部署前提见 [数据库接口补全说明](12-数据库接口补全与联调说明.md)。真实 MySQL、SMTP 和页面验收不因 H2 测试通过而勾选。

- P0 无阻断级缺陷；演示路径连续运行三次成功。
- 新电脑按 README 能在 30 分钟内启动。
- 压缩包不含 `node_modules`、`target`、数据库备份或本地数据文件，大小小于 20 MB。
- SQL 可在空库执行；报告 PDF、个人小结和大模型说明命名符合课程要求。
