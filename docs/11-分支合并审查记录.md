## 审查发现与修正

1. 成员管理原型没有调用真实接口，却在正式工作台中展示可操作的 mock 数据，可能造成已保存的误解。将预览路由限定为开发环境；正常工作台显示“待联调”，不开放 mock 操作。后端接口与前端封装保留，真实数据接入仍待开发者完成。
2. 数据库扩展说明原先要求直接执行基线脚本，但基线固定使用 narrative_studio，与独立测试库要求不一致。修正为先复制基线脚本并修改建库、选库名称，再显式选择隔离测试库执行扩展。扩展 SQL 不自动执行，本次未修改任何实际数据库。
3. 数据库扩展是后续功能的结构草案，不代表邮箱验证、发布快照、草稿等业务已经实现。相关服务校验与 MySQL 实测仍需后续完成。
