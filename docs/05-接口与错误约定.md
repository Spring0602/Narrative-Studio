# 接口与错误约定

Excel增量接口：POST /api/story-excel/inspect、/preview，以及 /api/projects/import-excel、/api/projects/{id}/import-excel。使用 multipart/form-data：file文件，options为application/json part；提交需confirm:true及expectedDigest。空图导入需编辑权限，预览不写库。详细字段与错误码见[Excel接口约定](15-Excel剧情图导入说明.md)。普通业务接口仍使用下方JSON约定。

2026-09-17 新增契约：变量 persistenceScope 默认 SESSION、可选 PROFILE；选择规则新增可空 unlockRule；模拟新增 progress/lockedChoices，步骤新增 progressBefore/progressAfter。/api/projects/{id}/player-progress 支持 GET、PUT及 POST /reset，可选 releaseId；修改需 confirm:true 和 expectedRevision，版本冲突409，运行中禁止清档/预置。JSON导出版本现为2，兼容导入1/2。完整字段及权限见[复杂解锁接口说明](14-跨模拟进度与复杂解锁说明.md)。下文旧版示例未使用新字段时仍保持单局行为。

## 1. 通用约定

- 基础路径：`/api`
- 内容类型：`application/json;charset=UTF-8`
- 鉴权：`Authorization: Bearer <JWT>`
- 时间：ISO 8601；服务端按 Asia/Shanghai 配置，数据库使用 DATETIME。
- ID：后端使用 `Long`；前端若未来 ID 超过 JS 安全整数，应改为字符串传输。

成功响应：

```json
{
  "success": true,
  "data": { "id": 1, "name": "示例项目" },
  "timestamp": "2026-08-27T10:00:00Z"
}
```

失败响应：

```json
{
  "success": false,
  "error": { "code": "FORBIDDEN", "message": "无权访问该项目" },
  "timestamp": "2026-08-27T10:00:00Z"
}
```

```json
{ "username": "writer01", "password": "password123", "displayName": "剧情策划" }
```

```json
{ "name": "雾中来客", "description": "双主角互动推理故事" }
```

```json
{ "username": "writer02", "memberRole": "EDITOR" }
```

世界观条目类型限定为 `SETTING`、`LOCATION`、`FACTION`、`HISTORY`、`RULE`、`OTHER`。归档项目只读；所有成员和内容接口都会同时校验当前用户、`projectId` 及子资源归属。

剧情节点类型限定为 `NORMAL`、`ENDING`，`nodeKey` 在项目内唯一，且每个项目只能有一个起点。结局节点不能创建出边；删除仍被其他选择指向的节点返回 `RESOURCE_IN_USE`。修改选择的 `targetNodeId` 即完成重连，`sortOrder` 用于同一源节点下排序。批量坐标请求最多包含 500 个节点，服务会先验证全部节点归属再写入，任一项非法时整批回滚。

## 4. HTTP 状态与错误码

| HTTP | 常用错误码 | 场景 |
|---:|---|---|
| 400 | `VALIDATION_ERROR`、`RULE_VALUE_INVALID` | 格式或规则值非法 |
| 401 | `UNAUTHORIZED`、`INVALID_CREDENTIALS` | 未登录、Token/密码无效 |
| 403 | `FORBIDDEN`、`PROJECT_ACCESS_DENIED` | 已登录但权限不足 |
| 404 | `NOT_FOUND` | 项目或资源不存在 |
| 409 | `CONFLICT`、`RESOURCE_IN_USE`、`INVALID_STATE` | 唯一冲突、被引用、状态不允许 |
| 500 | `INTERNAL_ERROR` | 未预期错误，服务端记录详情但不回传堆栈 |

## 5. 分页约定

数据量可能增长的列表采用 `page`（从 1 开始）、`size`（默认 20，最大 100），返回：

```json
{ "items": [], "page": 1, "size": 20, "total": 0, "pages": 0 }
```

项目内节点图默认一次加载整个图；课程版限制每项目 500 个节点。超过后再改为分区或增量加载。

### 6.1 状态变量

创建和修改请求：

```json
{
  "variableKey": "trust",
  "displayName": "信任值",
  "valueType": "INTEGER",
  "initialValue": "30",
  "description": "决定隐藏结局是否可用"
}
```

返回 `{id, projectId, variableKey, displayName, valueType, initialValue, description?}`。

- 标识匹配 `[A-Za-z][A-Za-z0-9_]*`，最长64字符、项目内唯一；显示名最长100字符；每项目最多200个变量。
- BOOLEAN、INTEGER、STRING 三种类型；值统一传字符串。INTEGER 是有符号64位十进制整数，不接受浮点数、指数格式、前导零或空白。BOOLEAN 仅接受 `"true"`、`"false"`。STRING 可为空，保持原文，最长500字符。
- 被规则引用的变量不可删除或修改类型，返回409 `RESOURCE_IN_USE`。可通过置空 description 清除说明。
- 存在 RUNNING 会话时所有变量写入返回409 `CONFLICT`，先结束运行中的会话。归档项目所有本周写接口均拒绝。

### 6.2 条件与效果整体替换

假设信任变量 ID 为501：

```json
{
  "conditions": [
    {"variableId": 501, "operator": "GTE", "expectedValue": "50", "conditionGroup": 0}
  ],
  "effects": [
    {"variableId": 501, "operation": "SUBTRACT", "operandValue": "10"}
  ]
}
```

- 请求必须同时包含 conditions、effects 数组，每个最多100项；传空数组清空对应规则。服务先完整验证，再在同一事务中替换。
- 条件组编号0至100：组内 AND、组间 OR；没有条件时选择直接满足。INTEGER 支持 EQ/NE/GT/GTE/LT/LTE，其余类型仅 EQ/NE。
- INTEGER 效果支持 SET/ADD/SUBTRACT，其余类型仅 SET；数组顺序就是执行顺序，服务生成 sortOrder。
- 返回 `{choiceId, conditions, effects}`；每条规则除输入字段外还有 id、sortOrder。规则 ID 在整体替换后可能改变。
- 所有变量必须属于路径中的项目；非法值或不匹配操作符返回400 `RULE_VALUE_INVALID`，旧规则保持不变。

### 6.3 会话、选择与快照

创建、重新开始、终止会话均无请求体。执行选择必须提交客户端当前步号：

```json
{"expectedStepNo": 0}
```

会话返回字段：

```json
{
  "id": 42,
  "projectId": 10,
  "testerId": 2,
  "status": "RUNNING",
  "currentNode": {"id": 102, "nodeKey": "middle", "title": "调查", "nodeType": "NORMAL"},
  "stepNo": 1,
  "state": {"trust": "50"},
  "availableChoices": [{"id": 1002, "targetNodeId": 103, "choiceText": "隐藏结局", "sortOrder": 0}],
  "deadEnd": false,
  "startedAt": "2026-09-08T16:00:00"
}
```

- status 为 RUNNING / COMPLETED / ABORTED。到达 ENDING 自动完成，返回 finishedAt；无可用选择但仍为普通节点时 deadEnd=true，可终止或重开。
- stepNo=0 保存起点状态；第一条执行结果为1。后续步骤返回 `id, stepNo, nodeId, choiceId?, stateBefore, stateAfter, createdAt`；nodeId 为该步到达节点，初始步骤没有 choiceId。
- 重复或过期 expectedStepNo 返回409 `INVALID_STATE`；禁用、条件不满足、已结束会话、超过10000步也返回该错误。非当前节点或跨项目选择返回404。
- 读取、执行、重开、终止及回放都限定会话创建者本人；同项目其他成员也不可访问。被移除的成员不再有权限。
- 状态值均为字符串，前端根据变量类型展示或使用 BigInt 处理整数，不能无条件转换为 Number。
- 历史回放读取原始快照；规则编辑不会重算已有步骤。普通会话按当前剧情与规则计算；新增发布版会话按 releaseId 使用冻结内容，详见第7节。
- 列表及步骤分页遵循第5节约定；size最大100。变量列表使用最多200项的完整列表。

### 6.4 前端联调入口

`frontend/src/api/rules.ts` 提供变量与规则类型及接口封装；`frontend/src/api/playtests.ts` 提供会话、选择、重开、终止、分页回放接口。B 负责将规则编辑器和玩家模拟器页面接入这些封装。点击选择时提交上一次响应的 stepNo，收到409后重新获取会话，避免盲目重试原操作。
