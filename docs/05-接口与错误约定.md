# 接口与错误约定

## 1. 通用约定

- 基础路径：`/api`
- 内容类型：`application/json;charset=UTF-8`
- 鉴权：`Authorization: Bearer <JWT>`
- 时间：ISO 8601；服务端按 Asia/Shanghai 配置，数据库使用 DATETIME。
- ID：后端使用 `Long`；前端若未来 ID 超过 JS 安全整数，应改为字符串传输。

成功响应：

```json
{
  "success": true,
  "data": { "id": 1, "name": "示例项目" },
  "timestamp": "2026-08-27T10:00:00Z"
}
```

失败响应：

```json
{
  "success": false,
  "error": { "code": "FORBIDDEN", "message": "无权访问该项目" },
  "timestamp": "2026-08-27T10:00:00Z"
}
```

## 2. 已实现接口

| 方法 | 路径 | 鉴权 | 说明 |
|---|---|---:|---|
| GET | `/health` | 否 | 健康检查 |
| POST | `/auth/register` | 否 | 注册并返回 Token |
| POST | `/auth/login` | 否 | 登录并返回 Token |
| GET | `/projects` | 是 | 当前用户可访问的项目 |
| POST | `/projects` | 是 | 创建项目，当前用户成为 OWNER |
| GET | `/projects/{projectId}` | 是 | 项目详情 |
| PUT | `/projects/{projectId}` | 是 | OWNER/EDITOR 修改项目 |
| DELETE | `/projects/{projectId}` | 是 | OWNER 将项目归档 |
| GET | `/projects/{projectId}/members` | 是 | 项目成员查看成员列表 |
| POST | `/projects/{projectId}/members` | OWNER | 按用户名添加 EDITOR/TESTER |
| PUT | `/projects/{projectId}/members/{memberId}/role` | OWNER | 修改成员角色 |
| DELETE | `/projects/{projectId}/members/{memberId}` | OWNER | 移除非 OWNER 成员 |
| GET/POST | `/projects/{projectId}/world-entries` | 成员 / OWNER、EDITOR | 查询或创建世界观条目 |
| GET/PUT/DELETE | `/projects/{projectId}/world-entries/{entryId}` | 成员 / OWNER、EDITOR | 查看、修改或删除世界观条目 |
| GET/POST | `/projects/{projectId}/characters` | 成员 / OWNER、EDITOR | 查询或创建角色档案 |
| GET/PUT/DELETE | `/projects/{projectId}/characters/{characterId}` | 成员 / OWNER、EDITOR | 查看、修改或软删除角色档案 |
| GET/POST | `/projects/{projectId}/story-nodes` | 成员 / OWNER、EDITOR | 获取完整剧情图或创建节点 |
| GET/PUT/DELETE | `/projects/{projectId}/story-nodes/{nodeId}` | 成员 / OWNER、EDITOR | 查看、修改或删除节点 |
| PUT | `/projects/{projectId}/story-nodes/positions` | OWNER、EDITOR | 在同一事务中批量保存节点坐标 |
| GET/POST | `/projects/{projectId}/story-nodes/{nodeId}/choices` | 成员 / OWNER、EDITOR | 查询或创建节点选择 |
| PUT/DELETE | `/projects/{projectId}/story-nodes/{nodeId}/choices/{choiceId}` | OWNER、EDITOR | 修改、重连、排序、启停或删除选择 |

注册请求示例：

```json
{ "username": "writer01", "password": "password123", "displayName": "剧情策划" }
```

创建项目请求示例：

```json
{ "name": "雾中来客", "description": "双主角互动推理故事" }
```

添加成员请求示例：

```json
{ "username": "writer02", "memberRole": "EDITOR" }
```

世界观条目类型限定为 `SETTING`、`LOCATION`、`FACTION`、`HISTORY`、`RULE`、`OTHER`。归档项目只读；所有成员和内容接口都会同时校验当前用户、`projectId` 及子资源归属。

剧情节点类型限定为 `NORMAL`、`ENDING`，`nodeKey` 在项目内唯一，且每个项目只能有一个起点。结局节点不能创建出边；删除仍被其他选择指向的节点返回 `RESOURCE_IN_USE`。修改选择的 `targetNodeId` 即完成重连，`sortOrder` 用于同一源节点下排序。批量坐标请求最多包含 500 个节点，服务会先验证全部节点归属再写入，任一项非法时整批回滚。

## 3. 接口路径基线

| 模块 | 路径基线 |
|---|---|
| 成员 | `/projects/{projectId}/members` |
| 世界观 | `/projects/{projectId}/world-entries` |
| 角色 | `/projects/{projectId}/characters` |
| 节点 | `/projects/{projectId}/story-nodes` |
| 选择 | `/projects/{projectId}/story-nodes/{nodeId}/choices` |
| 变量 | `/projects/{projectId}/state-variables` |
| 测试 | `/projects/{projectId}/playtests` |
| 执行选择 | `/projects/{projectId}/playtests/{sessionId}/choices/{choiceId}` |
| 检测 | `/projects/{projectId}/analysis-runs` |
| 问题 | `/projects/{projectId}/issues` |

即使子资源 ID 全局唯一，也必须保留 `projectId`，以清晰表达权限边界和防止越权访问。

## 4. HTTP 状态与错误码

| HTTP | 常用错误码 | 场景 |
|---:|---|---|
| 400 | `VALIDATION_ERROR`、`RULE_VALUE_INVALID` | 格式或规则值非法 |
| 401 | `UNAUTHORIZED`、`INVALID_CREDENTIALS` | 未登录、Token/密码无效 |
| 403 | `FORBIDDEN`、`PROJECT_ACCESS_DENIED` | 已登录但权限不足 |
| 404 | `NOT_FOUND` | 项目或资源不存在 |
| 409 | `CONFLICT`、`RESOURCE_IN_USE`、`INVALID_STATE` | 唯一冲突、被引用、状态不允许 |
| 500 | `INTERNAL_ERROR` | 未预期错误，服务端记录详情但不回传堆栈 |

## 5. 分页约定

数据量可能增长的列表采用 `page`（从 1 开始）、`size`（默认 20，最大 100），返回：

```json
{ "items": [], "page": 1, "size": 20, "total": 0, "pages": 0 }
```

项目内节点图默认一次加载整个图；课程版限制每项目 500 个节点。超过后再改为分区或增量加载。
