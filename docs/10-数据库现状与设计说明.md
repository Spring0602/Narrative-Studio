- 2026-09-10 已补齐对应的后端接口、权限、事务、固定发布试玩、知识快照和账户凭据流程；新后端要求20表扩展已存在。

## 2. 20 张表按业务说明

### 账户与项目

| 表名 | 作用 |
|---|---|
| `sys_user` | 保存用户账号、密码摘要、显示名、系统角色与状态。 |
| `narrative_project` | 保存剧情项目的名称、简介、负责人和项目状态。 |
| `project_member` | 保存用户加入项目后的项目内角色，实现用户与项目的多对多关系。 |
| `account_action_token` | 保存邮箱验证、找回密码等一次性凭据的摘要、用途、过期时间和使用状态。 |

### 角色与世界设定

| 表名 | 作用 |
|---|---|
| `world_entry` | 保存世界规则、地点、势力等世界观条目。 |
| `character_profile` | 保存角色姓名、简介、性格、目标和价值排序。 |
| `character_relation` | 保存角色之间有方向的关系，例如 A 信任 B。 |
| `character_knowledge` | 保存角色的知识条目、知识等级和获得节点。 |
| `node_character` | 保存角色在哪些剧情节点出场。 |

### 剧情与规则

| 表名 | 作用 |
|---|---|
| `story_node` | 保存剧情节点、正文、节点类型、起点标记和画布坐标。 |
| `story_choice` | 保存正式选项，连接源节点和目标节点。 |
| `story_choice_draft` | 保存尚未指定目标节点的选项草稿；草稿不会进入正式剧情运行。 |
| `state_variable` | 保存项目的状态变量及其类型、初始值。 |
| `choice_condition` | 保存选择分支可见或可选的条件。 |
| `state_effect` | 保存选择执行后对状态变量产生的效果。 |

### 模拟、检测与反馈

| 表名 | 作用 |
|---|---|
| `story_release` | 保存项目发布时的固定内容快照和版本号。 |
| `playtest_session` | 保存一次试玩会话的测试者、当前节点、状态和开始结束时间。 |
| `playtest_step` | 保存试玩过程的每一步、选择和执行前后状态快照。 |
| `detected_issue` | 保存结构检测发现的问题、严重级别、对象和处理状态。 |
| `test_feedback` | 保存测试者提交的标题、描述、会话和处理状态。 |

## 3. 本次新增或扩展的设计

### 新增表

| 内容 | 解决的问题 |
|---|---|
| `account_action_token` | 为邮箱验证和找回密码提供安全的一次性凭据记录。数据库只保存令牌摘要，不保存明文令牌。 |
| `story_choice_draft` | 允许创作者先保存未完成分支，不破坏正式剧情图必须有目标节点的规则。 |
| `story_release` | 发布时保存固定剧情快照，保证之后修改剧情不会影响已发布版本的试玩。 |

### 扩展既有表

| 表 | 新增内容 | 目的 |
|---|---|---|
| `sys_user` | `email`、`email_verified_at`、`token_version` | 支持邮箱找回密码、邮箱验证，以及修改密码后旧令牌失效。 |
| `test_feedback` | `step_id` 及索引 | 让反馈定位到具体测试步骤，便于查看对应节点和当时状态。 |
| `playtest_step` | `knowledge_before`、`knowledge_after` | 记录角色知识在每一步前后的快照，避免不同试玩会话相互影响。 |
| `playtest_session` | `release_id` 及索引 | 让试玩会话明确使用哪一个固定发布版本。 |

## 4. 表之间的主关系

```text
用户 ──< 项目成员 >── 项目
项目 ──< 角色 / 世界设定 / 变量 / 剧情节点
剧情节点 ──< 正式选项 >── 目标剧情节点
正式选项 ──< 条件、效果
项目 ──< 发布版本 ──< 试玩会话 ──< 试玩步骤
试玩步骤 ──< 测试反馈
```

## 6. 目前的边界

已有设计覆盖主要数据实体，不能仅按表数量认定完整需求验收通过。当前边界：

- 邮箱发送适配、找回密码和一次性凭据校验已实现；真实SMTP及确认页面待配置/开发。
- 发布快照生成、按release_id试玩、草稿原子转正已实现。
- 知识按获得节点更新独立会话快照已实现；不是通用知识推理或知识条件/效果系统。
- 结构检测和问题/反馈状态接口已实现；图形定位页面及真实性能指标待验收。
- 真实库结构证据、MySQL原生JSON/外键/并发测试、迁移可复现性、完整演示数据、页面联调仍待完成。
