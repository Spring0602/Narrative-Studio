# Excel 一键生成剧情关系图

更新：2026-09-17。功能已实现，自动化测试及构建通过；实际浏览器和真实 MySQL 联调仍待验收。AI 自动生成 Excel 暂不接入，不列为本阶段必须完成项。

## 1. 使用入口与流程

- 项目列表：点击“从 Excel 生成剧情图”，确认后新建本人拥有的项目并直接进入剧情图。
- 剧情节点页面：OWNER / EDITOR 在未归档项目中点击“Excel 生成关系图”。空图可导入当前项目；已有节点时只能新建项目，不覆盖或合并已有图。
- 选择 Excel → 选择工作表和表头行 → 核对字段、类型和分支映射 → 校验并预览 → 核对警告和全部节点/连线 → 勾选确认 → 一键生成。

预览只解析数据、不创建项目或节点；提交时再次解析、校验，结果摘要必须与预览一致。文件、映射或名称修改后，前端立即清除旧预览和确认状态。不要在请求超时后盲目重复提交：先刷新项目列表/剧情图确认结果；新建项目导入不是跨请求幂等接口。

界面明确提示：“这个 Excel 用于整理全部剧情节点和跳转关系，推荐先用 AI 整理 Excel，再人工核对后导入。”提供可复制的 AI 整理提示词，但不会调用 AI、上传到模型服务或要求 API Key。原 Excel 不会被修改。

## 2. 支持不同表头，不按游戏类型写死

表头名称只用于自动建议，实际映射按列号确定。支持常见中英文别名，例如“节点编号 / 剧情编号 / Node_ID”“标题 / 节点标题 / title”“剧情内容 / 正文 / content”。出现多个候选时不擅自选一个，留给用户确认。

任何自定义表头都可以映射，例如“事件代号”映射到节点编号、“命运篇章”映射到标题。表头可在前30行，顶部可保留说明行。工作表名称不固定，可手动选择。当前一次选择一张节点表及可选的一张连线表，不会自动合并多个路线工作表。

| 系统字段 | 要求 |
| --- | --- |
| 节点编号 | 必填，唯一且稳定，1–64位英文字母、数字、下划线或短横线 |
| 节点标题 | 必填，最多120字 |
| 剧情正文 | 可选，连同补充字段最多10000字 |
| 节点类型 | 可选；普通/结局及 NORMAL/ENDING 等自动识别，未知类型要求手动映射 |
| 场景 / 章节 | 可选，最多100字 |
| 是否起点 | 可选，支持是/否、true/false、1/0等 |

“战斗”“调查”“对话”等游戏专属类型可映射为普通节点，“真结局”“彩蛋结局”可映射为结局。该映射是导入转换，并不新增运行时节点类型。没有提供类型时默认普通节点，不凭标题猜测结局。

未映射的节点列默认以“【表格补充字段】”附加到节点正文，保留角色、路线、前置说明等信息；可手动关闭。关闭后预览会提示这些列不导入。连线表仅导入映射的源、目标、文本，其他列不保留，预览有明确提示。

## 3. 两种推荐结构

### A. 单表：每行一个节点，多组分支列

| 节点编号 | 节点标题 | 节点类型 | 是否起点 | 选项1 | 选项1目标 | 选项2文本 | 目标2 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| start | 港口抉择 | 普通 | 是 | 登船 | ship | 留在港口 | port |
| ship | 海上终章 | 结局 | 否 | | | | |
| port | 港口终章 | 结局 | 否 | | | | |

上表可直接照此整理到 Excel。每组“目标列＋选项文本列”生成一个分支，支持自动建议及手工增删列组。目标单元格一次只写一个节点编号，不把逗号列表或自然语言当作多个目标。最多24组，仍受64列总限制。

目标和文本都为空表示该节点没有此分支；有文本却没有目标时阻止导入；有目标但文本为空时使用“继续”。无分支组也可只导入节点，预览明确提醒尚未生成连线。

### B. 双表：全部节点＋每行一条连线

节点表：

| 节点编号 | 节点标题 | 剧情正文 | 节点类型 | 是否起点 |
| --- | --- | --- | --- | --- |
| start | 港口 | 船长发出了邀请。 | 普通 | 是 |
| ship | 海上终章 | 你选择了远航。 | 结局 | 否 |
| port | 港口终章 | 你决定留下。 | 结局 | 否 |

连线表：

| 源节点编号 | 目标节点编号 | 选项文本 |
| --- | --- | --- |
| start | ship | 登船 |
| start | port | 留在港口 |

分支多时优先双表，避免无限横向扩展。终点、独立节点、后续才解锁的节点也要列入节点表。循环、汇合、多路线通过连线表达，不把同一节点重复列成多个节点。跳转引用区分大小写；重复节点检测不区分大小写，兼容数据库唯一约束。

## 4. 校验、布局和规则边界

- 重复编号、无效跳转、重复的源/目标/文本组合、多个起点、结局出边、起点为结局等情况阻止导入。常见表格错误会显示工作表和行号。
- 可显式填写起点编号覆盖表内标记。没有标记也没有指定时默认使用第一个节点，并在预览提醒；首节点为结局时仍报错。
- 从起点按广度优先层次安排初始坐标，同层分行；不可达节点单独放列并提示。循环不会导致布局无限递归。初始布局不保证复杂图完全没有交叉，导入后可继续拖动调整。
- 普通节点无出边会提示，不能据此擅自设为结局。
- 导入选项默认启用。本功能不导入可执行条件、变量、效果或 unlockRule；自然语言前置条件只作为说明保留。请使用已有规则编辑器补充跨局解锁等规则，再发布和试玩。不要把刚导入的图直接当作条件已经配置完整的游戏。
- 沿用现有21表，不新增 SQL 迁移。本轮没有执行业务库 DDL 或修改真实项目。此前跨局功能要求的21表迁移仍然需要完成。

## 5. 文件与权限安全

支持未加密的 .xlsx / .xls，不支持 CSV、xlsm 或仅改扩展名的其他文件。文件上限5MB，multipart请求上限6MB；工作簿1–10张表，每张最多2030行、64列，节点最多500个、连线最多1000条。多余空白格式行/列也可能触发上限，请在 Excel 中删除无关区域。

.xlsx 还限制压缩包条目数1000和总解压大小20MB，拒绝重复包内文件名、VBA项目和嵌入对象。所有格式均不执行宏或公式；选中表的数据区存在公式/错误值时要求先粘贴为值。数据区/表头合并单元格会被拒绝，表头之前的说明区可合并。读取的是原始数据，不能依赖隐藏行或筛选隐藏内容；隐藏节点行仍导入并提示。

编号使用单元格显示值读取，建议按文本保存，避免 Excel 自动改成日期、科学计数法或丢失前导零。不会猜测、恢复已经丢失的编号。

所有接口要求登录。预览和检查不持久化导入文件，multipart临时文件由框架管理。导入新项目以当前身份建立 OWNER；导入当前空图要求 OWNER/EDITOR 且项目未归档，持有项目写锁后复核图为空。数据库写入在单一事务中执行，失败时回滚本次项目/节点/连线，不留下半成品。并发导入同一空图时后到请求会发现图已非空并拒绝。

## 6. 接口约定

基础路径 /api；本组接口使用 multipart/form-data，不能沿用普通 JSON 请求体。file 为二进制文件；options 为 application/json 类型的独立 part。响应沿用 ApiResponse。

| POST 路径 | 用途 |
| --- | --- |
| /story-excel/inspect | 返回工作表名称、行数、隐藏状态和前30行样本（单元格样本最多120字） |
| /story-excel/preview | 返回标准剧情 document、digest、warnings，不写数据库 |
| /projects/import-excel | 确认后新建项目 |
| /projects/{projectId}/import-excel | 确认后写入当前空图，不改项目名和简介 |

options 示例（使用双表）：

```json
{
  "name": "港口故事",
  "mapping": {
    "nodeSheet": "节点表",
    "headerRow": 1,
    "columns": {"nodeKey": 0, "title": 1, "content": 2, "nodeType": 3, "isStart": 4},
    "choiceSheet": "连线表",
    "choiceHeaderRow": 1,
    "choiceColumns": {"sourceNodeKey": 0, "targetNodeKey": 1, "choiceText": 2},
    "branches": [],
    "typeMappings": {},
    "preserveExtra": true
  }
}
```

列号从0开始、表头行从1开始。单表模式不传 choiceSheet、choiceColumns={}，用 branches:[{"targetColumn":5,"textColumn":4}] 配置列组。typeMappings 如 {"真结局":"ENDING","战斗":"NORMAL"}；startNodeKey 可显式指定起点。

提交时在同一 options 加入 confirm:true 和预览返回的 expectedDigest；后端重新生成标准剧情文档并比较 SHA-256 摘要，不信任客户端提供的节点预览。摘要不是鉴权凭证或防重复提交令牌。错误格式为400；缺少确认、摘要不匹配、图非空或已归档为409；权限不足403；未登录401；超出multipart大小限制413。
