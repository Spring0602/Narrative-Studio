## 2. 新增接口契约

统一前缀 /api，成功返回 ApiEnvelope.data。导出接口返回 JSON 文档，不自动下载附件；前端保存时取 data，不保存整个响应封装。

| 方法 | 路径 | 权限 |
| --- | --- | --- |
| GET | /projects/{projectId}/export | 项目成员，归档项目可读 |

### 2.1 剧情导入导出

顶层字段：schemaVersion=1、name（1～100）、description?（≤1000）、nodes（≤500）、variables（≤200）、choices（≤1000）。列表不能为空值，允许空数组；所有嵌套对象执行校验。

- nodes 沿用节点保存字段：nodeKey、title、content?、nodeType、scene?、isStart、positionX/Y。
- variables 沿用变量保存字段：variableKey、displayName、valueType、initialValue、description?。
- choices 使用 sourceNodeKey、targetNodeKey、choiceText、sortOrder、enabled、conditions、effects。
- conditions：variableKey、operator、expectedValue、conditionGroup。
- effects：variableKey、operation、operandValue。每项选择最多100条件和100效果，保留数组执行顺序。
- 标识不接受重复（含大小写变体）；引用按原标识精确匹配。无效引用/类型、非法结局出边等导致整个导入回滚。
- 不包含数据库ID、成员、账户、世界观、角色/知识/出场、草稿、发布或试玩历史；这是“剧情图交换格式”，不是项目完整备份。导入后发布仍需符合发布检查。
- 未完成剧情允许导出；不会因为导出而发布或执行剧情。导出超过格式容量会明确失败，不截断。

可直接使用 [双结局样例](../backend/src/test/resources/story-transfer-demo.json)。在已有登录 token 的独立测试环境调用：

```powershell
# $token 来自当前测试账户的登录响应，不写入仓库或日志。
$headers = @{ Authorization = "Bearer $token" }
$body = Get-Content backend/src/test/resources/story-transfer-demo.json -Raw -Encoding UTF8
$result = Invoke-RestMethod -Method Post -Uri http://localhost:8080/api/projects/import -Headers $headers -ContentType 'application/json; charset=utf-8' -Body ([Text.Encoding]::UTF8.GetBytes($body))
$result.data.id
```

此操作创建一个新测试项目。不会执行数据库 SQL；原 demo_story.sql 仍待 C 完善，不把 JSON 样例冒充已经交付的 SQL 演示数据。

### 2.2 结局覆盖

返回 releaseId?、totalSessions、completedSessions、runningSessions、abortedSessions、totalEndings、reachedEndings、coveragePercent 和 endings[]。

每个 ending 包含 nodeId、nodeKey、title、completions。覆盖率 = 有至少一次 COMPLETED 到达的结局数 / 本次选定版本定义的结局数，保留两位小数；无结局时为0。重复到达增加 completions，不重复增加 reachedEndings。

不传 releaseId 只统计 release_id IS NULL 的编辑稿会话，结局列表使用当前编辑稿定义；编辑稿改动可能改变其分母，因此稳定验收应发布后统计指定版本。其他项目 releaseId 被拒绝；其他用户即使是 OWNER，也不能看到你的覆盖历史。

### 2.3 AI 候选对话

请求示例：

```json
{"nodeId":101,"characterId":11,"direction":"让角色谨慎地询问钥匙来源","consent":true}
```

成功 data：{"text":"候选内容","saved":false}。角色必须属于项目且有效；TESTER、归档项目、跨项目资源或未同意发送资料不能调用。生成后再次校验编辑权限。

可选环境变量（启动 PowerShell / IDE 注入；Spring Boot 不自动加载 .env）：

```powershell
$env:AI_ENABLED = 'true'
$env:AI_ENDPOINT = 'http://127.0.0.1:11434/api/generate'
$env:AI_MODEL = '你已安装并测试过的模型名'
```

适配遵循 [Ollama Generate 官方接口](https://docs.ollama.com/api/generate)，使用 stream=false。未自动安装或下载模型，也未访问真实模型服务。没有 AI 配置时不要开启，编辑、检测、发布和试玩照常使用。

- 只发送选定节点标题/正文、角色名称/性格/目标和用户方向，不发送账户、密码、JWT或项目全库。
- 仅允许 HTTPS 或本机 HTTP；URL 来自部署配置，不接受请求提供URL；禁止重定向。
- 连接超时5秒、请求超时30秒、最多2个并发生成；限制生成512 token、响应64 KiB、候选6000字符。
- AI_UNAVAILABLE / 503 表示未启用、配置/服务异常、无效或过大输出；AI_BUSY / 429 表示并发已满；不伪造降级生成结果。
- 元数据日志仅记录候选字符数和耗时，不记录提示词或正文；候选必须人工复核，作为纯文本展示，不使用 v-html，也不能作为脚本运行。
